# Quora Kagaj · Cricket Creator Media Kit

Portfolio for @quora_kagaj (Vivek Singh), ready for GitHub Pages.

## Publish
1. Upload everything in this folder (index.html, images/, videos/) to a GitHub repository, e.g. `media-kit`.
2. In the repository: Settings → Pages → Source: "Deploy from a branch" → Branch: main, folder: / (root) → Save.
3. After a minute or two the page is live at https://vivekk264.github.io/media-kit/

To edit text, open index.html and change the words directly. To swap a photo, replace the file in images/ keeping the same name.
